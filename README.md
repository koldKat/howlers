# Семейни бисери

Лек семеен архив за детски реплики, случки, снимки и малки легенди. Записите са лични по подразбиране, могат да се споделят с поканен родител, а избрани моменти могат да се покажат в публичната лента.

## Какво може

- лични и публични записи с любими, категории, настроения и тагове
- общ архив за двама или повече родители
- снимка към запис, автоматично намалена до 512 KB
- текстово форматиране и собствени SVG емотикони
- търсене по дете, заглавие, текст и таг
- TXT експорт и изглед за печат или PDF
- автоматично обновяване чрез server-sent events
- динамични публични страници, `sitemap.xml` и `robots.txt`
- отделни връзки за публични записи и защитени със случаен код връзки за лични записи
- локален админ панел и почасови SQLite архиви

## Изисквания

- Node.js 18 или по-нов
- npm
- системната команда `zip` за автоматичните архиви

`better-sqlite3` обикновено използва готов двоичен пакет. Ако за платформата няма такъв, `npm install` ще изисква стандартни инструменти за компилиране на Node.js модули.

## Инсталиране и стартиране

```bash
git clone https://github.com/koldKat/howlers.git
cd howlers
npm install
npm start
```

Отвори `http://localhost:3019`.

При първото стартиране приложението създава `database.sqlite` и нужните таблици. Базата, WAL файловете, архивите и качените зависимости са изключени от Git.

## Настройки на средата

- `PORT`: HTTP порт, по подразбиране `3019`
- `DATABASE_PATH`: друг път до SQLite базата
- `DISABLE_BACKUPS=1`: изключва автоматичните архиви, полезно за тестове

Пример:

```bash
PORT=8080 DATABASE_PATH=/srv/howlers/database.sqlite npm start
```

## Данни и архиви

Основната база е `database.sqlite`. На всеки кръгъл час сървърът създава ZIP архив в `backups/` и премахва архивите, по-стари от 14 дни. Рестартирането не създава допълнителен архив веднага.

Снимките и аватарите се пазят като data URL директно в SQLite. Затова размерът на базата зависи и от броя снимки.

Не добавяй `database.sqlite` или съдържанието на `backups/` в публично хранилище. Те могат да съдържат лични семейни данни.

## Администрация

Админ панелът е на `http://localhost:3019/admin` и приема само заявки от localhost. От него могат да се преглеждат статистики, да се сменя публичността на записи, да се изчистват сесии, да се трият записи и потребители и да се изпълнява `VACUUM`.
