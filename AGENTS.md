# Workspace Instructions

## Documentation Rule
Whenever code in this app changes, is added, or is removed, review these files and update them if needed:
- `docs/USER_GUIDE.md`
- `docs/TECHNICAL.md`

Update the docs whenever the change affects any of the following:
- user-visible behavior
- UI wording or flow
- styling of important controls or dialogs
- setup or run instructions
- API routes or payloads
- authentication/session behavior
- database schema or storage behavior
- file structure that matters for maintenance

Do not wait for the user to remind you.
